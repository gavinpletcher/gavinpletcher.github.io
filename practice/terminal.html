opening a file in vim

to open a file in vim you need to follow these steps

  1. open the terminal
  2. use cd to navigate your directory
  3. use the command vim "file name" to open the file in vim

navigating and editing vim

  • use hjkl to move up, down, left, and right
  • use i to enter insert mode to make edits to
                    the file
  • make sure you are using opening and closing tags such as and
  • to show a computers direct output use the samp tag for example 404 not found
